## 🎮 Как работает

| Элементы интерфейса | Исходный цвет | Измененный цвет |
|---------------------|---------------|-----------------|
| 💬 **Имена собеседников в чатах** (`color_im_text_name`) | 🔵 `#71AAEB` | 🔴 **`#FF5C5C`** |
| 🔵 **Акцентные кнопки, ссылки, активные вкладки, бейджи** | 🔵 `#71AAEB` | 🔴 **`#FF5C5C`** |
| ⚠️ **Ошибки, негативные сценарии, деструктивные действия** | 🔴 `#FF5C5C` | 🔵 **`#71AAEB`** |
| ❤️ **Лайки и счетчики реакций** | 🔴 `#FF5C5C` | 🔵 **`#71AAEB`** |

**✨ Особенности скрипта:**
- ⚡ **Мгновенный запуск (0ms задержка):** Базовые стили и токены VKUI внедряются на этапе `document-start`, исключая мерцание при загрузке страниц.
- 💬 **Поддержка мессенджера VK:** Имена контактов в диалогах и чатах корректно окрашиваются в новый акцентный цвет.
- 🚀 **SPA & Динамика:** Полноценная поддержка переходов без перезагрузки страниц благодаря оптимизированному `MutationObserver`.
- 🔄 **Автообновление:** Поддерживает автоматическое обновление через Tampermonkey напрямую из GitHub репозитория.
