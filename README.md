## 🎮 Возможности и функции

| Функция | Описание |
|---------|----------|
| 🎨 **Выбор темы интерфейса** | Быстрое переключение между **Светлой**, **Тёмной** и кастомной **Snow Black** темой в разделе **«Внешний вид»**. |
| ✨ **«Своё оформление» чатов** | Добавлен пункт **«Своё»** в начало карусели тем со студией настройки: установка фото из галереи в качестве статичного фона, выбор цвета облачков сообщений и интерактивный Live-предпросмотр чата. |
| 💬 **Раздел «Мессенджер» во Внешнем виде** | Пункт «Внешний вид» перенесен из `m.vk.ru/mail/settings` в **«Настройки > Внешний вид > Мессенджер»** с сохранением всех нативных тем VK. |
| 🔕 **Скрытие подписей снизу** | Отключает текстовые подписи под иконками в нижней панели (*Главная, Поиск, Мессенджер, Клипы, Ещё*). |
| ⚙️ **Меню скрипта** | Настройки кастомизации: замена вкладки Поиск, отключение звонков, скрытие кружков и скрытие категорий чатов. |
| 🛠️ **Размер значков на нижней панели** | Интерактивное ручное управление размером (%) и толщиной линий (px) для иконок Друзья, Сообщества, Музыка и Видео (в «Debug script»). |
| 🐞 **Debug script & Диагностика** | Раздел системной информации, параметров устройства, быстрого копирования лога и очистки кэша. |
| 📞 **Отключение звонков** | Полное скрытие кнопки вызова / трубки из шапки диалогов и блокировка случайных звонков. |
| 📹 **Отключение кружков** | Скрытие кнопки записи видеосообщений (кружков) в нижней строке ввода сообщений чата. |
| 📁 **Скрытие категорий чатов** | Полное удаление плавающей панели категорий (*Все, Каналы, Бизнес, Чаты*) и её отступов. |
| 🔴 **Круглые счетчики сообщений** | Исправление растянутых овальных бейджей счетчиков в диалогах — теперь они имеют идеальную круглую форму. |
| 📬 **Фильтр «Только непрочитанные» в шапке** | Нижняя шторка фильтра полностью удалена на `m.vk.ru/mail`, а кнопка переключения фильтра перемещена в верхнюю панель мессенджера. |
| 🚫 **Скрытие кнопки «3 точки» в списке чатов** | Удалена ненужная кнопка вызова контекстного меню справа от диалогов на `m.vk.ru/mail`. |

**✨ Особенности скрипта:**
- ⚡ **Мгновенный запуск (0ms задержка):** Базовые стили и токены VKUI внедряются на этапе `document-start`, исключая мерцание при загрузке страниц.
- 💬 **Поддержка мессенджера VK:** Имена контактов в диалогах и чатах корректно окрашиваются в новый акцентный цвет.
- 💾 **Сохранение настроек:** Выбранные параметры сохраняются в локальном хранилище браузера и применяются моментально без перезагрузки.
- 🛡️ **Строгая изоляция настроек:** Меню управления появляется только в настройках внешнего вида и разделах скрипта, мгновенно очищаясь при переходах.
- 🚀 **SPA & Динамика:** Полноценная поддержка переходов без перезагрузки страниц и без фликеров текста.
- 🔄 **Автообновление:** Поддерживает автоматическое обновление через Tampermonkey напрямую из GitHub репозитория.

## ⚙️ Где найти настройки
1. Откройте **ВКонтакте** на мобильном устройстве или в мобильной версии (`m.vk.ru`).
2. Перейдите в **«Настройки»** (`m.vk.ru/settings`).
3. Доступные разделы:
   - **«Внешний вид»** — выбор темы интерфейса, подраздел **«Мессенджер»** (оформление всех чатов, фон из галереи, разное оформление в чатах) и скрытие подписей снизу.
   - **«Меню скрипта»** — замена вкладки Поиск, скрытие категорий чатов, отключение звонков и кружков.
   - **«Debug script»** — размер значков на нижней панели, диагностика, копирование лога и очистка кэша.

## ✅ Совместимость
