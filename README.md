## 🎮 Возможности и функции

| Функция | Описание |
|---------|----------|
| 🎨 **Выбор темы интерфейса** | Быстрое переключение между **Светлой**, **Тёмной** и кастомной **Snow Black** темой (со взаимной заменой акцентных цветов). |
| 🔀 **Кастомизация нижней панели** | Замена кнопки **Поиск** на любые другие разделы: *Друзья, Сообщества, Музыка, Видео, Закладки* (с автоматической заменой иконки, ссылки и мгновенным переходом). |
| 🛠️ **Кастомная настройка иконок** | Интерактивное ручное управление размером (%) и толщиной линий (px) для иконок Друзья, Сообщества, Музыка и Видео с живым превью и кнопкой копирования параметров. |
| 📞 **Отключение звонков** | Полное скрытие кнопки вызова / трубки из шапки диалогов и блокировка случайных звонков. |
| 📹 **Отключение кружков** | Скрытие кнопки записи видеосообщений (кружков) в нижней строке ввода сообщений чата. |
| 🔕 **Скрытие подписей снизу** | Отключает текстовые подписи под иконками в нижней панели (*Главная, Поиск, Мессенджер, Клипы, Ещё*), оставляя только аккуратные иконки. |
| 📁 **Скрытие панели папок в мессенджере** | Полное удаление плавающей панели категорий (*Все, Каналы, Бизнес, Чаты*) и её отступов, делая список чатов максимально компактным. |
| ⚙️ **Нативное меню настроек** | Лаконичное меню с нативным стилем VKUI прямо в разделе **«Настройки» → «Внешний вид»** (`m.vk.ru/settings?act=appearance`). |
| 🔴 **Круглые счетчики сообщений** | Исправление растянутых овальных бейджей счетчиков в диалогах — теперь они имеют идеальную круглую форму. |
| 📬 **Фильтр «Только непрочитанные» в шапке** | Нижняя шторка фильтра полностью удалена на `m.vk.ru/mail`, а удобная кнопка переключения фильтра перемещена в верхнюю панель мессенджера. |
| 🚫 **Скрытие кнопки «3 точки» в списке чатов** | Удалена ненужная кнопка вызова контекстного меню справа от диалогов на `m.vk.ru/mail` без ущерба для кликов и действий внутри самих чатов. |

**✨ Особенности скрипта:**
- ⚡ **Мгновенный запуск (0ms задержка):** Базовые стили и токены VKUI внедряются на этапе `document-start`, исключая мерцание при загрузке страниц.
- 💬 **Поддержка мессенджера VK:** Имена контактов в диалогах и чатах корректно окрашиваются в новый акцентный цвет.
- 💾 **Сохранение настроек:** Выбранные параметры сохраняются в локальном хранилище браузера и применяются моментально без перезагрузки.
- 🛡️ **Строгая изоляция настроек:** Меню управления появляется только в настройках внешнего вида и мгновенно уничтожается при переходе в чаты, ленту или профиль.
- 🚀 **SPA & Динамика:** Полноценная поддержка переходов без перезагрузки страниц и без фликеров текста.
- 🔄 **Автообновление:** Поддерживает автоматическое обновление через Tampermonkey напрямую из GitHub репозитория.

## ⚙️ Где найти настройки
1. Откройте **ВКонтакте** на мобильном устройстве или в мобильной версии (`m.vk.ru`).
2. Перейдите в **«Настройки» → «Внешний вид»** (`m.vk.ru/settings?act=appearance`).
3. В нижней части страницы появится карточка управления **🚀 VK Mobile Upgrade** с тумблерами включения/выключения функций.

## ✅ Совместимость
- Мобильные браузеры (Kiwi Browser, Firefox Mobile, Yandex Browser, Safari Userscripts)
- Десктопные браузеры (Chrome, Firefox, Edge, Opera, Brave)
- Менеджеры скриптов: Tampermonkey / Violentmonkey
